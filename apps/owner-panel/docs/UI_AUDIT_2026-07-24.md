## Perbaikan lintas halaman

1. `PageHeader` sekarang menumpuk secara aman pada layar kecil.
2. Dialog memiliki margin viewport, batas tinggi, dan scroll vertikal.
3. Error boundary tidak lagi menampilkan message/stack teknis kepada pengguna.
4. Tabel bersama memiliki scope header dan pagination yang dapat dibaca screen reader.
5. Konfirmasi hapus menunggu operasi async, mencegah klik ganda, dan menampilkan kegagalan.
6. Seluruh route internal yang ditautkan cocok dengan router.
7. Semua 51 halaman/tab dimasukkan ke regression mobile.
8. Kegagalan query aktif tidak lagi menyamar sebagai tabel kosong; layout menampilkan
   banner error global dengan aksi **Coba Lagi**.
9. Kontrol tanggal, pilihan tipe ekstra, dan ukuran logo struk dapat digunakan dengan
   keyboard dan menyatakan status pilihannya kepada teknologi bantu.

## Fungsi Routing Tiket Dapur

“Stasiun” bukan printer fisik dan bukan menu yatim. Stasiun adalah jalur kerja, misalnya
**Dapur**, **Bar**, atau **Dessert**, yang mengelompokkan kategori menu. Printer fisik
kemudian diikat ke salah satu stasiun dari aplikasi POS pada perangkat. Web hanya
mengelola nama stasiun dan pemetaan kategori; konfigurasi printer tetap disimpan lokal
di perangkat POS. Halaman kini menjelaskan alur ini dan menyediakan preview tiket.

## Audit Tombol dan Automation

Inventaris statis menemukan 224 tombol:

- 202 menggunakan komponen `Button` standar.
- 22 tetap berupa tombol native karena merupakan kontrol khusus seperti kalender,
  segmented filter, kartu meja, radio-card, dan navigasi sidebar.
- 0 tombol native tanpa `type` eksplisit.
- 0 tombol ikon tanpa `aria-label` atau nama aksesibel.
- 0 tombol dalam form yang bergantung pada perilaku submit bawaan browser.
- 12 kontrol setara tombol (menu item, tab, dan action dialog) juga diperiksa dan
  seluruhnya memiliki handler atau value yang sesuai.

Standar lintas tombol sekarang mencakup variant, ukuran ikon (`icon`, `icon-sm`,
`icon-xs`), focus ring keyboard, default aman `type="button"`, status disabled ketika
aksi async berjalan, dan dialog konfirmasi untuk aksi destruktif.

Automation yang tersedia:

- 112 deklarasi tes pada suite Playwright/API.
- 56 referensi interaksi klik/tombol dalam source tes.
- Smoke test seluruh route sekarang memeriksa kontrak setiap tombol yang terlihat:
  tombol wajib memiliki nama aksesibel dan `type` eksplisit.
- Perintah `npm run audit:buttons` mengaudit kontrak statis seluruh TSX dan gagal
  otomatis bila tombol tanpa aksi/type/label atau ukuran ikon menyimpang ditambahkan.
- Tes publik memverifikasi tombol tampil/sembunyikan password melalui keyboard dan
  memastikan seluruh tombol login memenuhi kontrak.

Automation belum dan tidak seharusnya mengklik semua tombol secara buta karena sebagian
aksi menghapus data, mengubah status, atau membuat transaksi. Aksi kritis diuji melalui
skenario terarah; kontrak seluruh halaman dijalankan setelah login menggunakan akun E2E.
