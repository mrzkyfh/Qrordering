# Mobile Development Notes

Jangan membuat akun, route, shell, atau layar khusus operator produksi.
Operasional produksi menggunakan tiket yang dicetak dari aplikasi Kasir.

Perubahan printer wajib mempertahankan:

- printer dapur dan bar;
- routing kategori ke stasiun;
- autoprint order dan void;
- antrean cetak serta retry;
- cetak ulang tiket terpilih.

Role manusia yang didukung adalah Owner, Admin, Manajer, dan Kasir. Akun
Perangkat Cabang adalah akun teknis, bukan staf.
