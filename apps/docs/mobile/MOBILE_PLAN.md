# Mobile Plan

Rencana lama yang menjanjikan akun dan layar operator produksi sudah
dipensiunkan. Acuan implementasi aktif:

- Role manusia: Owner, Admin, Manajer, dan Kasir.
- Admin dan Manajer setara pada cabang sendiri.
- Semua operasional mobile berjalan melalui shell Kasir.
- Printer dapur, tiket produksi, routing kategori/stasiun, autoprint, dan cetak
  ulang tetap dipertahankan.

Lihat docs/mobile/MOBILE_ARCHITECTURE.md dan docs/ROLE_DAN_HAK_AKSES.md untuk
kontrak terbaru.
